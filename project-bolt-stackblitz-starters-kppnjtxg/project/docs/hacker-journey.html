3 · The heartbeat

Sixty times a second, your game does three things.

Read the buttons. Update the world a tiny bit. Draw it. Repeat. That's a game loop, and every game ever made has one.

The counters on the right are real. They're running in your browser right now.

Key idea · delta time

Frames aren't perfectly even, so your engine multiplies every movement by the time that really passed. It also caps a frame at 50 ms (deep-signal-engine.ts:365), so switching tabs can't teleport enemies.

8 · Speed run

Every frame gets 16.7 milliseconds. Don't waste them.

At 60 frames a second, each frame has 1000 ÷ 60 = 16.7 ms to do all its work. Miss it and the game stutters.

Your backdrop never moves, but it's repainted every single frame. Watch the counter climb.

Speedrunner rule

Measure before you fix. Chrome DevTools › Performance › record five seconds of play. The tallest blocks are where the time goes.

★ Bonus · Think like a hacker

Your game is a locked room. You're holding the key.

Hackers ask one question: "What is this game trusting me with?"

The Signal Below runs on your computer, so you can talk to it. This kit is how. Four steps, no experience needed:

  1. Open the game and start a run (press Start Descent).
  2. Press F12 and click the Console tab. (Mac: Option + Command + J)
  3. Click Copy on the kit, paste it into the console with Ctrl + V, press Enter.
  4. Type jb.god() and press Enter. Walk into the enemies. Laugh.
Console
A text box in your browser where you can type code and run it right now.
State
The box where the game keeps your health, your gold and the enemies.
Function
A little machine. You say its name, like heal(), and it does one job.
Comment
A note for humans. It starts with // and the computer skips it.
Hacker rule #1

Only paste code you can read. Scammers say "paste this in the console for free skins" and steal accounts. This kit only touches the game tab on your own screen. Never paste code from strangers, Discord DMs, or any site where you're logged in. If you can't read it, don't run it.

Why it matters

Anything running on the player's computer can be changed by the player. That's why real games keep scores and prizes on a server and check them there. When you build a leaderboard, remember this page.
